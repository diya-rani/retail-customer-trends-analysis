# Retail Customer Trends & Shopping Behavior Analysis

## Project Overview
An end-to-end multi-disciplinary data analytics project investigating customer purchasing patterns, behavioral demographics, and transaction trends. This project integrates relational database querying, statistical analysis, and interactive dashboarding to deliver actionable commercial insights.

## Tech Stack & Tools
* **Database & Querying:** PostgreSQL (Complex Joins, Aggregations, CTEs)
* **Exploratory Data Analysis:** Python (Jupyter Notebook, Pandas, NumPy)
* **Visualization & Business Intelligence:** Power BI (`.pbix` dashboard)
* **Documentation:** Business Requirement Documents & Executive Summaries
